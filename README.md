# Présentation

Ce repo reproduit les figures du papier 'Existe t-il des trappes de sous développement à l'échelle des universités'. 

Le travail a été rédigé sur le logiciel Typst et peut-être accédé en mode lecture ci-dessous : 

https://typst.app/project/r5ky52oaV1tkcsWjkPzNbi

(Un dictionnaire des variables peut être retrouvé en page 3)

# Guide

Les fichiers Prep.R et Maps.R contiennent des morceaux de code reproduisant la collection des données via l'API OpenAlex et WDI par un call JSON nécessitant plus de deux semaines de veille. Il n'est pas nécessaire de les lancer.

Les fichiers de données bruts peuvent être retrouvés dans le dossier Data. Ils sont suffisants pour lancer le code de bout à bout.

Les rendus peuvent être retrouvés dans le dossier Output.
